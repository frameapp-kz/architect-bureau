# Atelier Orda — Architectural Bureau Catalog

Responsive catalog website (ICT6001, Lab Work 9).

- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS Grid + Flexbox, relative units only (`rem`, `%`, `vh`), mobile-first
- Burger menu and dark monochrome theme switch — pure CSS, no JavaScript
- Feedback form with `type="email"`, `type="tel"`, `required` and CSS validation states

Open `index.html` in a browser or visit the GitHub Pages link.
